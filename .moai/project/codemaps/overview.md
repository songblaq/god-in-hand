# God in Hand — 아키텍처 개요

> Android 스마트폰을 온디바이스 AI 에이전트 머신으로 전환하는 Bash 기반 설치기

---

## 시스템 정의

God in Hand는 Termux 환경에서 동작하는 쉘 스크립트 설치기로, Android 기기에 로컬 LLM 서빙 엔진, AI 에이전트 런타임, 스킬 시스템을 자동으로 구성한다. 인터넷 연결 없이 기기 자체에서 AI 추론을 수행하는 것이 핵심 목표다.

---

## 3계층 아키텍처

```
┌─────────────────────────────────────────────────┐
│  Layer 3: 스킬 & 플러그인                        │
│  OpenClaw 스킬 시스템, 사용자 정의 에이전트       │
├─────────────────────────────────────────────────┤
│  Layer 2: 에이전트 런타임                         │
│  OpenClaw (Node.js, Port 3000)                  │
│  AI 게이트웨이, 대화 관리, 툴 실행               │
├─────────────────────────────────────────────────┤
│  Layer 1: 모델 서빙                              │
│  Ollama (Port 11434) / llama.cpp               │
│  GGUF 모델 실행, REST API 제공                   │
└─────────────────────────────────────────────────┘
         ↕ 제어 플레인
┌─────────────────────────────────────────────────┐
│  Hub 대시보드 (Port 8080) + CLI (openclaw)       │
│  시스템 상태 모니터링, 모델 관리 인터페이스       │
└─────────────────────────────────────────────────┘
```

## 설계 패턴

### 1. 5단계 설치 오케스트레이터 패턴

`install.sh`는 각 단계를 함수로 분리한 순차적 파이프라인으로 동작한다.

```
Phase 0 (사전 점검) → Phase 1 (기존 설치 감지) → Phase 2 (권한 및 환경 설정)
→ Phase 3 (핵심 설치) → Phase 4 (검증 및 헬스 체크) → Phase 5 (Hub 설정)
```

각 단계는 독립적으로 오류를 처리하며, 실패 시 계속 진행할지 사용자에게 확인을 요청한다.

### 2. 소스 기반 라이브러리 로딩

`install.sh`는 실행 시 `lib/` 디렉토리의 모듈을 `source` 명령으로 동적 로드한다. curl 파이프 실행 환경에서는 먼저 리포지토리를 다운로드한 후 라이브러리를 로드하는 부트스트랩 패턴을 사용한다.

### 3. curl|bash 호환 패턴

표준 설치 경험(`curl -sL ... | bash`)을 지원하기 위해 stdin을 `/dev/tty`로 재연결하는 처리를 포함한다. `pkg`, `npm` 등 패키지 관리 명령은 `</dev/null`로 리다이렉트하여 스크립트 스트림 소비를 방지한다.

### 4. RAM 기반 모델 선택

`lib/models.sh`의 `recommend_models()` 함수는 감지된 RAM 용량에 따라 최적 모델 조합을 결정한다. 이는 디바이스 역할(hub/worker/power)과 연동된다.

### 5. JSON 카탈로그 기반 모델 관리

`config/models.json`이 모델 메타데이터의 단일 진실 원본(single source of truth)으로 동작한다. Python3 우선, grep 폴백의 이중 파싱 전략을 사용한다.

## 시스템 경계

| 경계 | 내부 | 외부 |
|------|------|------|
| 실행 환경 | Termux (Android, aarch64) | iOS, x86, 일반 Linux |
| 모델 서빙 | Ollama, llama.cpp | 클라우드 API |
| 에이전트 | OpenClaw | 다른 에이전트 프레임워크 |
| 저장 위치 | `~/.god-in-hand/` | 시스템 경로 |
| 네트워크 | localhost (포트 3000, 8080, 11434) | 외부 인터넷 (초기 설치 시만) |

---

## 핵심 제약 조건

- Android 10+ (API 29) 필수
- CPU 아키텍처: aarch64 (arm64) 전용
- Termux: F-Droid 버전 필수 (Play Store 버전 비지원)
- 최소 RAM: 4GB (권장 6GB+)
- 최소 저장 공간: 5GB (권장 10GB+)
- Node.js v22+ 필요 (OpenClaw 실행)
