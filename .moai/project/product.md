# God in Hand — 제품 문서

## 프로젝트 개요

**God in Hand**는 스마트폰을 독립적인 온디바이스 AI 에이전트 머신으로 전환하는 오픈소스 프레임워크입니다. 클라우드 API 없이 Android 스마트폰에서 대형 언어 모델(LLM)을 로컬로 실행하고, AI 에이전트를 통해 파일 관리, 브라우저 자동화, 위치 서비스 등의 실제 작업을 수행할 수 있습니다.

- **버전**: v0.1.0
- **라이선스**: MIT
- **저장소**: github.com/songblaq/god-in-hand
- **지원 플랫폼**: Android 10+ (Termux, ARM64)

---

## 대상 사용자

- **프라이버시 우선 사용자**: 개인 데이터를 클라우드 서버에 전송하지 않고 AI를 활용하려는 사용자
- **오프라인 환경 사용자**: 인터넷 연결이 제한적이거나 불안정한 환경에서 AI 기능이 필요한 사용자
- **Android 고급 사용자**: Termux를 통한 Linux 환경 활용에 익숙한 사용자
- **AI 연구자 및 실험자**: 소형 디바이스에서 LLM 성능을 실험하고자 하는 개발자 및 연구자
- **비용 절감 사용자**: 월정액 AI 서비스 비용 없이 AI 기능을 활용하고자 하는 사용자

## 핵심 기능

### 1. 로컬 LLM 서빙

클라우드 연결 없이 스마트폰에서 직접 대형 언어 모델을 실행합니다.

- **Ollama 지원**: REST API(localhost:11434)를 통한 모델 서빙
- **llama.cpp 지원**: `--engine llamacpp` 옵션으로 대체 엔진 사용 가능
- **RAM 기반 모델 자동 선택**: 디바이스의 가용 RAM에 따라 최적 모델 자동 추천

| 가용 RAM | 추천 모델 구성 |
|---------|-------------|
| 4GB     | Qwen3 0.6B |
| 6GB     | Gemma4 E2B + Qwen3 0.6B |
| 10GB    | Gemma4 E4B + Qwen3 0.6B |
| 14GB+   | E4B + Qwen3.5 35B MoE + Qwen3 0.6B |

### 2. AI 에이전트 런타임

OpenClaw 프레임워크(Node.js 기반)를 통해 실제 작업을 수행하는 AI 에이전트를 구동합니다.

- **Browser 스킬**: 웹 브라우저 자동화
- **Files 스킬**: 파일 시스템 접근 및 관리
- **Cron 스킬**: 예약 작업 실행
- **Camera 스킬**: 카메라 기능 접근
- **GPS 스킬**: 위치 서비스 활용
- **Termux:API 스킬**: Android 시스템 기능 접근

### 3. 멀티 디바이스 메시

여러 Android 기기를 역할별로 연결하여 분산 AI 컴퓨팅 환경을 구성합니다.

| 역할 | RAM 요건 | 주요 기능 |
|-----|---------|---------|
| Hub | 12GB+   | 기본 게이트웨이, 쿼리 라우팅 |
| Worker | 8GB+ | 백그라운드 작업 처리 |
| Power | 16GB+  | 복잡한 추론 작업 |
| iOS (원격) | - | WiFi로 Android 허브에 연결 |

### 4. 웹 대시보드 (Hub)

단일 HTML 파일(`hub/index.html`)로 구성된 경량 관리 인터페이스입니다.

- 실시간 디바이스 상태 모니터링 (RAM, CPU, 배터리, 온도)
- 연결된 노드 간 쿼리 라우팅 관리
- 스킬 활성화 및 비활성화
- 모델 다운로드 및 관리

### 5. 이중 언어 지원

`lib/i18n.sh`를 통해 한국어와 영어를 지원합니다.

- `--lang ko`: 한국어 인터페이스
- `--lang en`: 영어 인터페이스 (기본값)
- curl|bash 파이프 방식과 호환되는 순수 Bash 구현

### 6. 5단계 자동 설치

`install.sh`가 전체 설치 과정을 자동으로 처리합니다.

1. **Preflight**: 환경 사전 점검 (Android 버전, ARM64 확인)
2. **Existing Check**: 기존 설치 감지 및 업그레이드 경로 제공
3. **Permissions**: 필요 권한 확인 및 요청
4. **Install**: 의존성 및 핵심 컴포넌트 설치
5. **Verify**: 설치 검증 및 헬스 체크 실행, Hub 대시보드 설정

## 주요 사용 사례

- **개인 AI 비서**: 인터넷 연결 없이 스마트폰에서 언어 모델과 대화

- **오프라인 번역/요약**: 네트워크 없이 문서 번역 및 요약 작업 수행
- **IoT 엣지 컴퓨팅**: 스마트폰을 AI 기능이 있는 IoT 허브로 활용

## 핵심 차별점

### 클라우드 독립성

모든 처리가 디바이스 내에서 완결됩니다. OpenAI, Anthropic, Google 등 외부 API를 호출하지 않습니다. 월정액 서비스 비용이 발생하지 않으며, 인터넷 연결이 없어도 완전히 작동합니다.

### 프라이버시 우선 설계

사용자 데이터가 기기를 벗어나지 않습니다. 대화 내용, 파일 내용, 위치 정보 등 모든 입력이 로컬에서만 처리됩니다.

### RAM 인식 최적화

디바이스의 실제 가용 메모리를 감지하여 최적의 모델을 자동 선택합니다. 4GB의 저사양 기기부터 16GB+ 고사양 기기까지 모두 지원하며, 메모리 부족으로 인한 크래시를 방지합니다.

### curl|bash 호환 설치

`curl -fsSL https://get.example.com | bash` 방식의 원클릭 설치를 지원합니다. 추가 도구 없이 단일 명령으로 전체 환경이 구성됩니다.

### Termux 네이티브 통합

Android의 Termux 환경에 최적화되어 있습니다. Android API(카메라, GPS, 알림 등)에 직접 접근할 수 있으며, 루팅 없이도 광범위한 시스템 기능을 활용합니다.
